# clawd

An original retro pixel-art crab, the sample character pack of zbuddy and
the one built into the firmware. Generated by `tools/mkpack.py`:

```sh
tools/mkpack.py characters/clawd app/src/builtin_pack.c
```

Seven states, 96x96 GIFs, 24x24 art pixels. Push it to a device with
`tools/bridge_sim.py -p <port> push characters/clawd`, or drop the folder
on the desktop app's Hardware Buddy window.
